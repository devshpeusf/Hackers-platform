# Scanner decoder assets

Generated by `node scripts/prepare-scanner-decoder.mjs` during dev/build/install.
The script copies the exact reader WASM from the installed `zxing-wasm` package,
verifies its upstream SHA-256, and names it with the matching library version.
The generated WASM is ignored by Git; production builds recreate it.

Current source: `barcode-detector@3.2.3` → `zxing-wasm@3.1.6` reader.
Official sources: https://github.com/Sec-ant/barcode-detector and
https://github.com/Sec-ant/zxing-wasm. The JS wrapper is MIT-licensed; the reader
contains ZXing-C++ under Apache-2.0. See LICENSE.barcode-detector.txt,
LICENSE.zxing-wasm.txt, and LICENSE.zxing-cpp.txt in this directory.

The fallback explicitly fetches this same-origin binary before initialization.
There is no runtime CDN dependency, service worker, or offline cache.
